VISUAL DESIGN — PART 2: DESIGN

1. What overall style will best represent you (minimalist, creative, professional, etc.)?

A minimalist, professional style inspired by Wikipedia. The design uses a white background, readable text, blue links, and thin gray dividers.

2. What color scheme will you use and why?

White (#FFFFFF), dark text (#202122), blue links (#3366CC), light gray backgrounds (#F8F9FA), and gray borders (#A2A9B1 and #C8CCD1). These colors keep the content readable and the design consistent.

3. What fonts will you use for headings and body text?

Georgia for main headings and Arial for body text, navigation, and smaller headings. Times New Roman, Helvetica, and generic serif or sans-serif fonts provide fallbacks.

4. How will your design reflect your personality or field?

The organized layout reflects my interest in practical, easy-to-use software. My personal photo and hobbies add personality while the project descriptions highlight my technical work.

5. What layout will your homepage follow?

Navigation at the top, followed by my introduction, About Me and skills, Selected Work, Resume, Contact, and footer. My photo appears beside the About Me text.

6. How will you organize project sections visually?

Projects appear in horizontal rows on desktop. Each includes a title, description, technologies, project-page link, and status/type label. On smaller screens, the rows stack vertically.

7. Will the site be mobile-friendly? How will you ensure responsiveness?

Yes. CSS media queries adjust the layout at 780 pixels. Flexbox allows content to wrap, project rows stack vertically, navigation becomes collapsible, and images scale to fit the page.

8. What visual hierarchy will guide visitors?

My name is the largest heading. Section headings and dividers organize the page. Smaller headings identify projects and skills. Blue links indicate actions visitors can take.

9. How will consistency be maintained across pages?

All pages share the same stylesheet, navigation labels, typography, colors, image styling, and footer format. Project pages also have consistent headings and links back to the homepage.

10. How will accessibility be considered (contrast, font size, readability)?

The site uses readable text, dark text on a light background, semantic HTML, descriptive image alt text, and visible keyboard focus styles. The mobile menu uses aria-controls and aria-expanded and supports the Escape key.

11. Will you use icons, images, or illustrations? Why?

Yes. My portrait introduces me, project interface images help explain my work, and an MH favicon identifies the website in browser tabs. Interface previews use sample content where noted.

12. What portfolio websites inspired your design?

Wikipedia inspired the final design, especially its article layout, typography, blue links, and clear section headings. I adapted that style for my personal portfolio.

INTERACTION / FUNCTIONALITY — PART 3: INTERACTIVITY

1. What interactive elements will your site include (navigation menus, buttons, forms)?

Navigation links, project links, resume view/download links, professional profile links, an email link, a back-to-top link, and a collapsible mobile menu. Links and buttons also have hover and focus effects.

2. Will your site include a contact form? How will it work?

No. The Contact section includes an email link that opens the visitor's configured email application, along with GitHub and LinkedIn links.

3. What JavaScript features will you implement?

JavaScript opens and closes the mobile menu, changes its button label, and updates aria-expanded. Clicking a navigation link closes the menu. Pressing Escape closes it and returns keyboard focus to the menu button.

4. How will users receive feedback from interactions?

Links underline on hover, keyboard focus outlines identify selected controls, and the menu button changes between Menu and Close Menu. The menu appears or disappears based on its current state.

5. How does interactivity improve the user experience?

The mobile menu makes navigation easier on smaller screens. Links help visitors move between sections and project pages. Hover and keyboard focus effects make available actions easier to recognize.
